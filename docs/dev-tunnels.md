# Connect across PCs on your LAN

CoCern uses a direct connection between the adapter and the hub on your LAN. If an installed adapter points to a dev tunnel, reconnect it using the hub’s LAN address.

On the hub, open **Connect → Add another PC** and copy the HTTPS address, certificate fingerprint and join code. On the other PC, open CoCern Setup and select **Join another hub**. [Windows setup and repair](windows-setup.md)
