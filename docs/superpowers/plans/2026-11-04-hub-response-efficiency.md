## Original rationale and file plan (rulings above take precedence)

Source inspected at `2a79671724e60aac8d3944af25508f63d555812d`. Roslyn loaded the feature solution with ten projects. Visual Studio had the primary checkout running and was inspected read-only. The supplied two-day totals are 10.9M tokens for 22,040 background status calls, 4.0M for 533 worker lists, and 2.4M for 581 task reads. The 9.7M inbox tokens and poll cadence belong to Claude089.

**Worker directory.** `ControlAggregate.ListWorkers` projects every repository entry with `DirectoryEntry.Worker`, pages it, then fits machine summaries. For the compact default, keep live entries, stale entries with `LastSeen > IdleCutoff(now, MinCloseSessionsIdleMinutes)` (proposed existing 60-minute floor plus existing activity-report slack), and known `OwnsWork(now)` or `MailHold == Holding` entries regardless of age. Reuse the current incarnation/freshness test. Count omitted rows once per repository before paging. No label-based classification. Keep identity, binding version and presence fields on compact rows and expose complete original rows, including bindings, with `includeStale:true`. Keep the existing machine totals over the full authorized repository and distinguish visible from omitted counts. Opt the internal `MachineDirectory.DirectoryWorkersAsync` into full enumeration: it treats absence from a complete page sequence as evidence that a chat closed. Directory mail/work marks are eventually consistent, and a mail hold is recorded only after an idle expiry is refused. If every actually unread/action-bearing session must always be visible, this projection alone cannot establish that. Manager must decide this before turning on suppression. Use a stable session-ID order and a seek-after continuation for compact pages, or a restart on membership change, so expiry between pages cannot skip surviving entries. Keep old full-view cursor and piece semantics.

**Task board.** Apply the projection only in `TaskBoardAggregate.ListTasks`. Drop repeated `sections` there. Emit `{taskId,state:"completed"}` only when `TaskArchiving.Archivable(task,now)` is true. Its existing predicate excludes live claims and unresolved actions. `openOnly:true` filters out only those safely collapsible rows before ordinal paging, including workflowless legacy tasks in the open population. Preserve remaining claim, version, workflow and recovery fields. Use a seek-after continuation for the new filter if lease expiry can change membership mid-read. Validate filter types and reject combinations with `taskId`, `section`, or `sinceRevision`. Keep the existing shared `Summary` for `DeltaPage`, single-task fallback and archival/detail reads. Offer a full board-list shape for raw consumers relying on the former fields. Changing unqualified defaults still requires Manager approval or negotiated rollout; NODE5's waiver does not cover these responses.

**Status.** Existing adapter `ConditionalRead` hashes a complete forwarded answer, strips `ifNoneMatch`, and sends `knownEtag` only for feedback. The background readers currently ask for detail; they do not negotiate this hub fast path. Leave that contract intact. Add a separately negotiated hub conditional detail read for pure session polls, with an initial empty validator requesting a full response plus a scoped status tag, followed by `{unchanged:true,statusTag}` on match. Compute from current authorized status after session verification, control status, standing/attention evaluation and applicable reply add-ons. Include repository, board, verified caller/session, privilege/visible grant state, incarnation, selection and the semantic fields the consumer uses. Scope the opt-in contract to semantic status, explicitly excluding observational timestamps only if proven irrelevant; include effective freshness/lease/expiry transitions, cancellation content, wake/hold transitions and standing revision. No cache of privileged payloads. Use a freshly evaluated answer on every call, return full data on uncertainty, and exclude reads with history, piggyback writes or other non-poll options. This first pass saves wire tokens; skipping aggregate reads would require stronger invalidation evidence. Coordinate tag and fallback format with Claude089 before they adopt it. Existing callers continue getting full status by default.
